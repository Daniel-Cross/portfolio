# danielcross.dev

Developer portfolio for Daniel Cross — senior React Native / Web3 engineer (ex-MetaMask, footballAlpha). Live at [https://danielcross.dev](https://danielcross.dev).

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```

## Test

```bash
npm run test
# or directly:
npx vitest run
```

## Lint

```bash
npm run lint
```

## Deploy

The site deploys via Vercel's Git integration: every push to `main` triggers an automatic production deployment. No manual deploy step or Vercel CLI usage is required — Vercel builds and serves the project directly from this repository.

Live URL: **https://danielcross.dev**

## Stack

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · shadcn/ui · Vitest + React Testing Library
