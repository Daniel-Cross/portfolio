## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry → local build | Third-party package code executes at install/build time (supply-chain surface) |
| visitor browser → served HTML/CSS/JS | Untrusted client renders our static output; response headers govern browser behavior |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-SC | Tampering | npm scaffold packages (next, typescript, tailwindcss, shadcn, lucide-react) | high | mitigate | Blocking, non-auto-approvable `checkpoint:human-verify` (Task 1) before first install; 01-RESEARCH.md Package Legitimacy Audit confirms official orgs + no postinstall scripts |
| T-01-01 | Tampering / Spoofing | Whole-site framing (clickjacking) | medium | mitigate | `X-Frame-Options: DENY` header in `next.config.ts` (Task 3) |
| T-01-02 | Information Disclosure | Response content-type sniffing | low | mitigate | `X-Content-Type-Options: nosniff` header (Task 3) |
