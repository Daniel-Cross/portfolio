<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| visitor browser → clipboard API | Client-side clipboard write on user gesture (D-15) |
| visitor browser → external links (LinkedIn, GitHub, mailto) | Outbound navigation / mail client |
| visible email text → automated scrapers | Public plaintext email address exposure |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-08 | Information Disclosure | Visible `hello@danielcross.dev` harvested by scrapers | low | accept | Explicitly accepted per D-15 ("spam-scraping risk accepted; zero friction wins") — documented locked decision, not an open threat |
| T-01-09 | Denial of Service | `navigator.clipboard` unavailable/throws | low | mitigate | Feature-detected + silent-fail; always-present `mailto:` link is the guaranteed fallback path (Task 3) |
| T-01-10 | Tampering | External `_blank` links (LinkedIn/GitHub) reverse-tabnabbing | low | mitigate | `rel="noopener noreferrer"` on `_blank` links (Task 3) |
</threat_model>
